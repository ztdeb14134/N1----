# 我的 N1 学习档案

从 **2026-10-05** 开始，以每天约一小时准备 N1。已知基础是约两年前通过 N2；现在的保留程度将通过实际练习确认。

## 新对话怎么开始

在 Codex 中打开这个同一文件夹，再开启新对话。根目录的 [AGENTS.md](AGENTS.md) 是给助手的固定规则；你的进度存在文件里，新对话需要读取它们才能接续。

可以直接复制：

> 请按本文件夹的 AGENTS.md 规则，读取我的学习档案、近期学习记录和复习队列，生成今天的 N1 学习计划并保存为 Markdown。总用时控制在 60 分钟内，包含完整材料、练习题和作答区，先不要给答案。结合我已有记录安排复习；如果还没有作答记录，请先安排轻量诊断。

第一次会先诊断，不预设考试日期或薄弱项。如果新对话没有打开这个工作目录，可先明确路径：`D:\vscodelibrary\N1学习计划`。普通聊天若无法访问本地文件，就不能自动读取或更新此档案。

## 每天怎么使用

1. 要求生成今天的计划，打开 `02_每日学习/日期_学习计划.md`。
2. 按计划学习，把答案填入末尾的作答区，或按题号直接发在同一对话中。
3. 完成后要求批改。助手会保存当天的作答与批改，并更新日志、进度、错题和复习日期。
4. 下一次新开对话时，仍打开这个文件夹，让助手先读档案。

批改时可以复制：

> 我已完成这份学习计划。请读取计划中的作答区和我在聊天中提交的答案，逐题批改并保存作答与批改文件，同时更新当前进度、学习日志、错题本和复习队列。不要把未做的题记为已完成。实际用时：___ 分钟；查词/看提示/复听情况：___。

答案格式：`2026-10-05-Q01：B，信心 1`。信心 0＝猜测，1＝不确定，2＝确定。建议附用时及困难，但未提供也可以先批改。

## 重要约定

- **生成计划 ≠ 完成学习 ≠ 已经掌握**。只有实际作答、批改和复测才更新相应证据。
- 断更后继续即可。可以说“最近没学，今天恢复”；积压内容会按优先级分批安排。
- 如果只有 30 分钟，直接说“今天只有 30 分钟”，助手会缩减当天任务。
- 已提交的题目和首次答案会保留；重复批改不会把同一天算两次。
- 暂时没有目标考试日期或教材也可以开始；以后提供信息会写入学习者档案。
- 已有档案只完成建档，**尚未生成今日学习计划，尚无学习或测评记录**。下一次新对话即可开始。
