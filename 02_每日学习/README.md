# 每日学习文件

已生成 [2026-10-05 首次诊断计划](2026-10-05_学习计划.md)，尚无作答记录。每日状态以 [学习日志](../00_学习档案/学习日志.md) 为准；新对话先读取根目录规则及学习档案。

命名方式：

- `YYYY-MM-DD_学习计划.md`：当天任务、材料、题目和空白作答区。
- `YYYY-MM-DD_作答与批改.md`：用户提交后保存原始答案、标准答案、解析和后续处理。

同一天默认一份计划、一份批改。作答前不创建含标准答案的文件；已提交题目不覆盖。跨天补交仍使用原计划日期，批改中另记实际提交日期。每日文件通过学习日志索引，不需要把整份历史复制到新对话。
